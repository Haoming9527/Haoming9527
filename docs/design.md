# Economist: capital meets code

An exchange-inspired GitHub profile built from repository-hosted images and ordinary Markdown. The supplied NYSE photograph anchors the identity; it has no added lettering. The distinctive feature is a real commit-diff candlestick chart, not decorative market data.

## Visual direction

- Midnight navy `#101d2d`: terminal canvas, coordinated with the photograph.
- Slate `#8fa3b8`: secondary information.
- Paper `#edf3f8`: primary typography.
- Jade `#80d1b6`: additions / positive net changes.
- Coral `#e69c93`: deletions / negative net changes.
- Brass `#d0b879`: project symbols and neutral emphasis.
- Typography: Georgia for the personal wordmark; system sans serif for prose; Consolas for numbers, dates and project symbols. SVGs use installed system fallbacks, without remote fonts.
- Layout: full-width photograph, identity and links, one prominent market chart, then a short thesis, linked project listings, stack, public contributions and sourced track record. Left aligned; no trophy wall, skill percentages, visitor counter or fabricated valuation.

Review against the brief: the initial lettering on the banner was removed at the user's request. The nickname lives in accessible Markdown instead. Market metaphors organize real evidence; none imply trading returns or that line count measures quality. Mobile uses larger type and fewer chart labels in dedicated SVGs. GitHub light and dark themes receive coordinated assets through `picture` sources.
